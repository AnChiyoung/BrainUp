# BrainUp 코인 설계 (v1 초안)

> 목표: 매일 돌아올 이유(재방문)를 만들고, 사용자가 **원해서 보는** 보상형 광고 노출을 늘린다.
> 원칙: 코인은 게임 안에서만 쓰는 재화로 현금 가치가 없고, **판매하지 않는다**(유료 결제는 MVP 제외).
> 기록은 지금처럼 기기에만 저장한다(계정 연동은 이후 Firebase 작업에서).

## 1. 얻는 방법

| 출처 | 코인 | 조건 |
|---|---:|---|
| 첫 실행 환영 선물 | +100 | 1회 |
| 게임 완료 | +10 | 결과 화면 도달 시마다. 하루 최대 20판(200코인)까지 |
| 개인 최고 기록 갱신 | +20 | 게임별, 갱신할 때마다(첫 기록 포함) |
| 보물상자(오늘의 도전 3/3) | +50 | 하루 1회 |
| └ 보물상자 **광고 보고 2배** | +50 추가 | 보물상자를 열 때 선택, 하루 1회 |
| 연속 기록 달성 | +100 / +300 | 7일째 / 30일째 |

**하루 기준 획득량**
- 네 게임 1판씩만 하는 경우: 40 + 50 = **90코인**
- 보물상자 2배 광고까지 보는 경우: **140코인**
- 여러 판을 하고 최고 기록을 갱신하는 날: 200 이상

## 2. 쓰는 곳 (상점)

| 아이템 | 가격 | 설명 |
|---|---:|---|
| **불꽃 방패** | 150 | 하루를 놓쳐도 연속 기록 유지. 최대 2개 보유, 놓친 날 자동 사용 |
| 브레니 색 (4종) | 200 ~ 500 | 마스코트 색: 민트, 하늘, 노랑, 무지개(500) |
| 패턴 타일 스킨 (2종) | 400 | 보석(기본) → 과일, 별 |
| 지도 테마 (2종) | 600 / 1,000 | 밤하늘(기본) → 바다, 우주정거장 |

가격 감각: 방패 약 2일, 브레니 색 3~6일, 타일 5일, 테마 1~2주.

## 3. 규칙

- 코인 잔액은 0 미만이 될 수 없다. 구매는 잔액이 충분할 때만 가능.
- 꾸미기 아이템은 한 번 사면 영구 보유, 언제든 바꿔 낄 수 있다.
- 불꽃 방패는 "어제 오늘의 도전을 완료하지 못했고 연속 기록이 1일 이상"일 때 앱을 연 순간 자동 사용.
  - 사용 시 "불꽃 방패가 연속 기록을 지켰어요!" 알림.
  - 이틀 이상 놓치면 하루당 1개씩 사용, 부족하면 기록 초기화.
- 보물상자 2배는 보상형 광고를 **끝까지 시청**했을 때만 지급(기존 이어하기와 같은 방식).
- 게임 완료 코인 하루 20판 제한은 같은 게임 무한 반복으로 코인을 찍어내는 것을 막기 위함.

## 4. 저장

- 코인 잔액, 보유 아이템, 착용 아이템, 방패 개수: Room(신규 테이블) 또는 DataStore.
- 코인 변동 내역(출처·금액·시각)을 남겨 하루 제한 계산과 문제 추적에 쓴다.

## 6. 화면 변경

- 지도: 상단 HUD에 코인 잔액. 보물상자가 열 수 있는 상태면 빛나며 "열기!" 표시.
- 보물상자 열기 팝업: +50, "광고 보고 2배" / "그냥 받기".
- 결과: 획득 코인 내역(완료 +10, 최고 기록 +20)과 합계.
- 하단 탭: 지도 / 트로피 / **상점** / 설정.
- 상점: 잔액, 불꽃 방패, 브레니 색, 타일 스킨, 지도 테마.
- 앱 실행 시 방패 사용 알림.

# 스토어 등록정보 초안

> 뇌 기능 개선·치매 예방 등 **의학적 효과를 암시하는 표현은 쓰지 않는다**(설계서 원칙, Play 정책상 허위·오해 소지 표현 금지).

## 앱 이름 (30자 이내)

BrainUp - 매일 3분 두뇌 훈련

## 간단한 설명 (80자 이내)

숫자 기억·반응 속도·패턴 기억, 하루 3분 미니게임으로 매일 도전하고 기록을 갱신하세요!

## 자세한 설명

하루 3분, 가볍게 즐기는 두뇌 미니게임!

BrainUp은 짧고 간단한 네 가지 미니게임으로 매일 도전하는 앱입니다. 회원가입 없이 바로 시작하세요.

■ 숫자 기억력
잠깐 보였다 사라지는 숫자를 순서대로 입력하세요. 라운드를 통과할수록 숫자가 늘어납니다.

■ 반응 속도
화면이 초록색으로 바뀌는 순간 터치! 5번 측정한 중앙값과 최고 기록을 확인하세요.

■ 패턴 기억
빛나는 타일의 순서를 기억하고 똑같이 터치하세요. 라운드마다 하나씩 길어집니다.

■ 색깔 달리기
다가오는 문과 같은 색 버튼을 눌러 결승선까지 달리세요. 연속으로 맞히면 점점 빨라집니다.

■ 오늘의 도전
네 게임을 하루에 한 번씩 완료하면 오늘의 도전 성공! 연속 완료 기록을 이어가 보세요.

■ 나의 기록
게임별 최고 기록과 최근 7일 점수를 한눈에 볼 수 있습니다.

• 회원가입·로그인 없음, 기록은 내 기기에만 저장됩니다.
• 무료 앱이며 광고가 포함되어 있습니다. 게임 플레이 중에는 광고가 나오지 않습니다.
• 반응 속도 기록은 기기의 화면·터치 지연이 포함된 참고용 수치입니다.

## 스크린샷 구성 제안 (휴대전화, 세로)

1. 홈 — 오늘의 도전 카드 + 게임 목록
2. 숫자 기억력 — 숫자 표시 중
3. 반응 속도 — 초록 "터치!" 화면
4. 패턴 기억 — 타일 점등 중
5. 결과 — "개인 최고 기록 갱신!"
6. 기록 — 연속 완료 + 최근 7일 그래프

> 스크린샷은 광고 배너가 나오지 않는 화면이나, 광고 영역을 가린 상태로 찍는 것을 권장한다.
